Pairs

“A W” / “B W” are wins when on opposite teams. p = exact two-sided binomial test on decided head-to-heads (draws excluded); below 0.05 is unlikely to be luck.

Method

  • Per-game stats = total ÷ appearances. Win rates = wins ÷ (W + D + L).
  • Streaks run over each player's own appearances in order; missed weeks don't break a streak, a draw breaks win/loss streaks.
  • Win impact = player's win % minus the win % their team-mates have without them, weighted by games shared.
  • G+A is only awarded if its winner is different from both the Golden Boot and Assist King winners.
  • Ties are shared. Default thresholds: 12+ apps for individual awards (11 doesn’t qualify), 8+ games for pairings (together, or decided games against each other for Nemesis), 3+ captaincies for the captain awards. Adjust them above to explore; Reset returns to these.
  • Own goals are credited to no one.
